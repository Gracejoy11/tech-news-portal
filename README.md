# 🌐 TechCrunch News Portal
A professional web application that fetches and displays real-time technology news using the TechCrunch (WordPress) REST API.

## 🛠️ Features
- **Dynamic Data Fetching:** Uses Axios to pull live posts from an external API.
- **Server-Side Rendering:** Built with Node.js, Express, and EJS for a fast, seamless experience.
- **Professional UI:** Styled with a custom "Card" layout and a clean color palette.
- **Error Handling:** Robust logic to handle network issues and API restrictions.

## 💻 Tech Stack
- **Backend:** Node.js & Express
- **Frontend:** EJS (Embedded JavaScript) & CSS3
- **API:** TechCrunch WordPress REST API
- **HTTP Client:** Axios

## 📋 How to Run
1. Run `npm install` in the terminal to download dependencies.
2. Start the server using `node index.js`.
3. Open `http://localhost:3000` in your web browser.
